ようこそ!0からのホームページ作成研修へ 🌸

新卒からベテランまで、全SEを対象としたWeb制作の実践研修です。

さくらちゃん はじめまして!この研修のナビゲーターを務める「さくらちゃん」です🌸 この研修では、ホームページが表示される仕組みから、実際に自分で作って世界に公開するまでを、ひとつずつ丁寧に学んでいきます。 プログラミングが初めての方も、経験豊富なベテランの方も、それぞれのペースで進められるようになっているので、安心してついてきてくださいね!

受講の記録(まずはここから)

日付とお名前を記入して「開始/再開する」ボタンを押してください。受講記録が「何月何日 名前」の形でテキストに記録されます。

⚠️ 名前を記入しない場合、受講記録は記録されません。

途中で中断した場合も、次回ここで日付と名前を入力すれば続きの章から再開できます(同じ日付・同じ名前の記録が既にある場合、二重には記録されません)。

🔧 管理者向け:記録テキストの設定

受講記録は「保存先フォルダ」内の kenshu-log-1.txt に1行ずつ追記され、500行に達すると自動的に kenshu-log-2.txt へ切り替わります。 最初に一度、保存先フォルダ(社内共有フォルダも可)を設定してください。未設定の場合、記録はこのブラウザ内に保存され、下のボタンで同じ形式のテキストとして取り出せます。

この研修のゴール

  • Webページが表示される仕組みを、人に説明できるようになる
  • HTML / CSS / JavaScript を使って、0からWebサイトを作れるようになる
  • 作ったサイトを GitHub Pages でインターネットに公開できるようになる
  • 2026年現在のWeb業界のトレンドを把握し、現場での会話についていけるようになる

カリキュラム一覧

第1章

Webの仕組み

URLを入力してからページが表示されるまでに何が起きているのか。DNS・HTTP・ブラウザの役割を理解します。

 第2章

HTML基礎

ページの「骨組み」を作るHTML。タグの書き方から、意味のあるマークアップ(セマンティクス)まで。

 第3章

CSS基礎

ページに「見た目」を与えるCSS。セレクタ、ボックスモデル、詳細度という3つの山を越えます。

 第4章

レイアウトとレスポンシブ

FlexboxとGridで自在に配置し、スマホでもPCでも美しく表示されるページを作ります。

 第5章

JavaScript基礎

ページに「動き」を加えるJavaScript。変数・関数・DOM操作・イベントを実際に動かして学びます。

 第6章

総合演習

ここまでの知識を総動員して、架空企業のコーポレートサイトを0から作り上げます。レベル別課題つき。

 第7章

GitHubで公開

Git/GitHubの基本操作を学び、作ったサイトをGitHub Pagesで世界に公開します。

 第8章

最新トレンド

モダンCSS、フレームワーク、アクセシビリティ、AI活用まで。2026年の現場を見渡す章です。
