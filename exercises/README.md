# 演習フォルダの使い方

このフォルダには、第2〜5章の演習(自己紹介ページ制作)用のファイルが入っています。

## フォルダ構成

| フォルダ | 内容 |
| --- | --- |
| `starter/` | 演習のひな形。これをコピーして自分の作業フォルダを作り、書き進めてください |
| `answer/` | 解答例(第2〜5章の演習をすべて反映した完成形) |

## 進め方

1. `starter` フォルダを丸ごとコピーし、自分の名前のフォルダ(例:`yamada`)を作る
2. 各章の演習の指示に従って `index.html` / `style.css` / `script.js` を育てていく
3. **詰まっても、すぐに `answer` を見ないこと!** まず教材の該当章を見返す → MDNで調べる → それでもダメなら answer を「一部だけ」見る
4. 完成したら answer と見比べて、書き方の違いを味わう(違っていても動けば正解です)

## 解答例について

`answer` は「唯一の正解」ではなく「一つの例」です。
クラス名や色が違っていても、次の点が満たせていればOKです。

- 正しい文書構造(DOCTYPE / html / head / body、viewportメタタグ)
- セマンティックタグ(header / main / footer)での構造化
- 外部CSS・外部JSファイルへの分離
- スマホ表示で崩れないこと
- Consoleにエラーが出ていないこと
