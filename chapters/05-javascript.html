第5章 JavaScript基礎

ページに「動き」を与えるプログラミング言語、JavaScriptに入門します。

さくらちゃん ついにプログラミング言語の登場です!でも安心してください。Webでよく使うJavaScriptのパターンは 「①要素を取ってきて → ②イベントを待ち受けて → ③中身やクラスを変える」——ほぼこれだけなんです。 この「三拍子」を合言葉に進みましょう!

5-1. JavaScriptを書く場所 基礎

CSSと同様、実務では外部ファイル方式が基本です。bodyの閉じタグ直前で読み込むのが定番(HTMLを読み終わってから実行させるため)。

<body>
  <h1>こんにちは</h1>
  ...ページの内容...

  <script src="main.js"></script>  ← 最後に読み込む
</body>
💡 console.log() と DevTools の Console タブ
console.log("こんにちは"); と書くと、DevToolsのConsoleタブに文字が出力されます。 プログラムの動きを確認する開発者の目です。この章の学習中はConsoleタブを開きっぱなしにしましょう。 F12 → Consoleタブに直接コードを打ち込んで実験もできます。

5-2. 変数:値に名前を付ける 基礎

const name = "さくら";   // const:あとで変更しない値(基本はこちら)
let count = 0;           // let:あとで変更する値
count = count + 1;       // letなら再代入できる

// 値には種類(型)がある
const text = "こんにちは";   // 文字列(クォートで囲む)
const price = 1500;          // 数値
const isOpen = true;         // 真偽値(true / false)
const members = ["田中", "鈴木", "佐藤"];  // 配列(値のリスト)
const user = { name: "田中", age: 25 };    // オブジェクト(名前付きの値の集まり)
⚠️ var は使わない
古い教材にはvarが登場しますが、スコープの罠が多い旧式の書き方です。現代のコードはconstを基本、再代入が必要なときだけletです。

5-3. 関数と条件分岐 基礎

// 関数:処理のまとまりに名前を付けて、何度でも呼べるようにする
function greet(name) {
  return "こんにちは、" + name + "さん!";
}
console.log(greet("田中"));   // → こんにちは、田中さん!

// 条件分岐:状況に応じて処理を変える
const hour = 15;
if (hour < 12) {
  console.log("おはようございます");
} else if (hour < 18) {
  console.log("こんにちは");
} else {
  console.log("こんばんは");
}

// 繰り返し:配列の全要素に同じ処理をする
const members = ["田中", "鈴木", "佐藤"];
members.forEach(function (m) {
  console.log(m + "さん、出席");
});

5-4. DOM操作:三拍子の実践 全員

ブラウザはHTMLを読み込むと、DOM(Document Object Model)という「JavaScriptから触れるページの模型」を作ります。この模型を操作すると、画面がリアルタイムに変わります。

冒頭の「三拍子」をコードにするとこうなります。

// ① 要素を取ってくる(CSSと同じセレクタが使える!)
const btn = document.querySelector("#greet-btn");
const output = document.querySelector("#output");

// ② イベントを待ち受ける(クリックされたら…)
btn.addEventListener("click", function () {
  // ③ 中身を変える
  output.textContent = "ボタンが押されました!🌸";
});

実際に動かしてみましょう。

✏️ コード(メッセージを変えてみよう)
🖥️ 表示結果(ボタンを押してみて!)

よく使うDOM操作まとめ

やりたいこと書き方
要素を1つ取るdocument.querySelector(".menu")
要素を全部取るdocument.querySelectorAll(".item")
文字を変えるel.textContent = "新しい文字";
クラスを付ける/外す/切替el.classList.add / remove / toggle("open")
入力欄の値を取るinput.value
クリックを待つel.addEventListener("click", 関数)

5-5. 実践パターン:クラスの付け外しでUIを作る 全員

現場のJavaScriptで最頻出のパターンは、「CSSで2つの状態を用意しておき、JSでクラスを切り替える」です。開閉メニュー、タブ、モーダル…あらゆるUIがこの応用でできています。

✏️ コード(開閉パネルの仕組み)
🖥️ 表示結果(ボタンで開閉します)

🎓 ベテラン向けコラム:モダンJSの必須知識アップデート ベテラン向け

「JavaScriptはjQueryの時代で止まっている」という方向けの、現在の標準機能ダイジェストです。

  • アロー関数 … (a, b) => a + b。現場のコードはほぼこの記法
  • テンプレートリテラル … `こんにちは、${name}さん`。文字列連結の+はもう使わない
  • 分割代入・スプレッド構文 … const { name, age } = user; / [...arr1, ...arr2]
  • async/await + fetch … 非同期通信の標準形。XMLHttpRequestやコールバック地獄は過去のもの 
    const res = await fetch("https://api.example.com/users");
const users = await res.json();
  • ESモジュール … import / exportがブラウザ標準に。<script type="module">
  • jQueryの終焉 … querySelector、classList、fetchの標準化により、新規案件でjQueryを採用する理由はほぼ消滅。ただし保守案件では現役なので「読める」必要はまだある
