第1章 Webの仕組み

コードを書き始める前に、「ホームページが表示される」とはどういうことかを理解しましょう。

さくらちゃん いきなりコードを書くこともできるけど、仕組みを知っている人と知らない人では、トラブル対応力に大きな差が出ます。 現場で「画面が表示されません」と言われたとき、どこを疑えばいいか判断できるのは仕組みを知っている人です。焦らず土台から固めましょう!

1-1. インターネットとWebは別物 基礎

まず、混同しがちな2つの言葉を整理します。

用語 正体 例えるなら
インターネット 世界中のコンピュータをつなぐ通信網(インフラ) 道路網
Web(WWW) インターネット上で文書(ページ)を公開・閲覧する仕組み 道路を使った宅配便サービス

メールやオンラインゲームも「インターネット」を使いますが、「Web」ではありません。Webは、インターネットという道路の上を走るサービスのひとつです。

1-2. クライアントとサーバー 基礎

Webの世界は、この2人の登場人物の「リクエスト(要求)とレスポンス(応答)」で成り立っています。

  • クライアント … ページを「見たい」側。あなたのPCやスマホのブラウザ(Chrome、Edge、Safariなど)
  • サーバー … ページを「渡す」側。ページのファイルを保管し、要求に応じて送り返すコンピュータ
[クライアント]                          [サーバー]
   ブラウザ ── ①「このページください」 ──▶ Webサーバー
            ◀── ②「はい、どうぞ(HTML)」──
   ③受け取ったHTMLを画面に描画する

この「ください」「どうぞ」のやり取りのルール(約束事)がHTTP(HyperText Transfer Protocol)です。暗号化された安全版がHTTPSで、現在はHTTPSが標準です。

1-3. URLの読み方 全員

普段何気なく見ているURLは、次のパーツに分解できます。

https://www.example.co.jp/company/about.html
└─┬─┘  └───────┬───────┘└────────┬────────┘
 スキーム      ドメイン名            パス
(通信方式)  (どのサーバーか)   (サーバー内のどのファイルか)
  • スキーム … 通信方式。httpsなら暗号化された通信
  • ドメイン名 … サーバーの住所にあたる名前
  • パス … サーバーの中のフォルダ・ファイルの場所

1-4. DNS:名前から住所を引く電話帳 全員

コンピュータ同士は、実際にはIPアドレス(例:93.184.216.34)という数字で通信します。しかし人間が数字を覚えるのは大変なので、www.example.co.jpのようなドメイン名を使います。

この「名前 → 数字」の変換を担当するのがDNS(Domain Name System)です。電話帳や連絡先アプリのようなものだと思ってください。

1-5. ページが表示されるまでの全体の流れ 全員

ブラウザにURLを入力してEnterを押すと、裏側ではこれだけのことが一瞬で起きています。

  1. DNSに問い合わせ … ドメイン名からサーバーのIPアドレスを調べる
  2. サーバーに接続 … HTTPSで安全な通信路を確立する
  3. リクエスト送信 … 「このパスのページをください」と要求する
  4. レスポンス受信 … サーバーがHTMLファイルを返す
  5. 追加リソースの取得 … HTMLの中で参照されているCSS・JavaScript・画像も同様に取得する
  6. レンダリング … ブラウザがそれらを組み立てて画面に描画する
さくらちゃん ⑥に注目!ブラウザが受け取るのは「完成した画面」ではなく、HTML・CSS・JavaScriptという「材料」なんです。 材料から画面を組み立てるのはブラウザの仕事。だから私たちがこれから学ぶのは、ブラウザへの「指示書」の書き方なんですよ🌸

1-6. 3つの言語の役割分担 基礎

Webページは3つの言語の分業で作られます。家づくりに例えると分かりやすいです。

言語 役割 家に例えると
HTML 文書の構造・内容(見出し、段落、画像…) 骨組み・間取り
CSS 見た目・装飾(色、配置、大きさ…) 内装・外装
JavaScript 動き・振る舞い(クリックしたら開く、など) 電気設備・自動ドア

1-7. 開発に必要な道具 基礎

実は、Webページ作りに特別なソフトは不要です。必要なのはこの2つだけ。

  • テキストエディタ … コードを書く道具。本研修では Visual Studio Code(VS Code) を推奨(無料)
  • ブラウザ … 書いたページを表示・確認する道具。Google Chrome または Microsoft Edge を推奨
💡 開発者ツール(DevTools)を今すぐ開いてみよう
ブラウザで F12 キーを押すと「開発者ツール」が開きます。いま見ているこのページのHTMLやCSSがそのまま見られます。 現場のフロントエンド開発者が一日中開いているツールです。今日から友達になりましょう。
🎓 ベテラン向けコラム:HTTPの現在地 ベテラン向け

「HTTPといえば1.1」の時代は終わりました。現在の主要サイトの多くは HTTP/2(1接続での多重化)や HTTP/3(TCPではなくUDPベースのQUICを使用)で配信されています。 接続確立のオーバーヘッド削減とヘッドオブラインブロッキングの解消が主目的で、DevToolsのNetworkタブの「Protocol」列で確認できます(h2 / h3 と表示されます)。

また、CDN(Contents Delivery Network)経由の配信が当たり前になり、「サーバー=1台の物理マシン」というモデルは実態と離れつつあります。エッジで完結する構成(エッジコンピューティング)は第8章で触れます。
