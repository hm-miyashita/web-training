第3章 CSS基礎

HTMLという骨組みに、色・大きさ・余白という「見た目」を与えていきます。

さくらちゃん CSSでつまずく人の9割は、「セレクタ」「ボックスモデル」「詳細度」の3つのどれかでつまずきます。 逆に言えば、この3つの山さえ越えれば、CSSは怖くありません。この章はその3つに集中しますね!

3-1. CSSの書き方と適用方法 基礎

CSSは「どこの(セレクタ)、何を(プロパティ)、どうする(値)」の3点セットで書きます。

h1 {
  color: red;
  font-size: 24px;
}
└┬┘  └──┬──┘ └─┬─┘
セレクタ プロパティ  値
(どこの) (何を)  (どうする)

CSSをHTMLに適用する方法は3つありますが、実務では③の外部ファイル方式が基本です。

方法書き方使いどころ
① インライン <p style="color:red"> 原則使わない(修正が地獄になる)
② styleタグ headの中に<style>…</style> 小さな実験・1ページ完結のとき
③ 外部ファイル <link rel="stylesheet" href="style.css"> 実務の標準。全ページで共有できる

ライブエディタで試しましょう(ここでは実験用に②のstyleタグ方式を使います)。

✏️ コード(編集できます)
🖥️ 表示結果

3-2. セレクタ:狙った場所だけを装飾する 全員

「全部のpじゃなくて、このpだけ赤くしたい」を実現するのがセレクタです。最重要はクラスセレクタ。

セレクタ書き方意味
要素セレクタ p { } すべての<p>要素
クラスセレクタ .alert { } class="alert"が付いた要素。実務の主役
IDセレクタ #header { } id="header"の要素(idはページ内で一意)
子孫セレクタ .menu a { } class="menu"の中にある<a>
疑似クラス a:hover { } マウスが乗っている状態の<a>
✏️ コード(編集できます)
🖥️ 表示結果
💡 クラス名の付け方
red-text(見た目)ではなくalert(役割)のように、「何のためのものか」で名付けるのがコツです。 後で「警告は赤じゃなくオレンジにしよう」となったとき、red-textという名前だと嘘になってしまいます。

3-3. ボックスモデル:すべての要素は箱である 全員

CSS最重要概念です。すべてのHTML要素は、4層構造の「箱」として描画されます。

┌─────────────────────────────┐
│         margin(外側の余白)          │
│  ┌───────────────────────┐  │
│  │      border(枠線)              │  │
│  │  ┌─────────────────┐  │  │
│  │  │  padding(内側の余白)    │  │  │
│  │  │  ┌───────────┐  │  │  │
│  │  │  │ content(中身)  │  │  │  │
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
  • margin … 箱の外側の余白(隣の要素との距離)
  • border … 枠線
  • padding … 箱の内側の余白(枠線と中身の距離)
  • content … テキストや画像そのもの
✏️ コード(paddingとmarginの数字を変えてみよう)
🖥️ 表示結果
💡 迷ったらDevToolsのComputedタブ
F12で要素を選択すると、その要素のボックスモデルが図で表示されます。「余白がどこから来ているか分からない」ときはまずここを見る。これはプロも毎日やっている操作です。

3-4. よく使うプロパティ 基礎

プロパティ役割例
color文字色color: #d6607e;
background背景(色・画像・グラデーション)background: #fdeef2;
font-size文字サイズfont-size: 1.2rem;
font-weight文字の太さfont-weight: bold;
text-align行内の揃えtext-align: center;
width / height幅 / 高さwidth: 300px;
border-radius角丸border-radius: 8px;
box-shadow影box-shadow: 0 2px 8px rgba(0,0,0,.2);

色の指定方法

  • 色名 … red、pink など(手軽だが実務では稀)
  • 16進数 … #d6607e(実務の主流。#RRGGBBで赤緑青の強さ)
  • rgb / rgba … rgba(214, 96, 126, 0.5)(4つ目の値は不透明度)

サイズの単位

単位意味使いどころ
pxピクセル(固定)枠線、影など細かい部分
remルート要素の文字サイズ基準(通常16px=1rem)文字サイズはこれが現代の標準。ユーザーのブラウザ設定を尊重できる
%親要素に対する割合幅の指定
vw / vh画面の幅 / 高さに対する割合画面いっぱいの表現

3-5. カスケードと詳細度:スタイルの喧嘩の勝敗ルール 全員

同じ要素に複数のスタイルがぶつかったとき、どちらが勝つのか。CSSの名前(Cascading Style Sheets)の由来でもある重要ルールです。

  1. 詳細度が高いセレクタが勝つ … ID(#)> クラス(.)> 要素名 の順に強い
  2. 同じ詳細度なら、後に書いたほうが勝つ
p { color: black; }        /* 詳細度:低 */
.alert { color: orange; }  /* 詳細度:中 ← クラスが勝つ */

<p class="alert">この文字はorangeになる</p>
⚠️ !important は最終兵器(=使わない)
color: red !important;と書くと詳細度を無視して勝てますが、後から誰も上書きできない呪いのコードになります。 「!importantだらけのCSS」は荒れた現場の代名詞。詳細度を理解して、正しく勝ちましょう。
🎓 ベテラン向けコラム:詳細度戦争の現代的解決 ベテラン向け

大規模開発での詳細度管理は長年の課題でしたが、近年は根本的な解決策が標準化されています。

  • カスケードレイヤー(@layer) … 「reset層 < base層 < components層」のようにCSS全体に優先順位の層を宣言でき、詳細度より層の順序が優先される。全モダンブラウザ対応済み
  • :where() … 詳細度0のセレクタを書ける。ライブラリ側が上書きしやすいスタイルを提供するときの定番
  • CSSネスト … Sassなしでネイティブにネストが書けるようになった(全モダンブラウザ対応済み)
  • CSS変数(カスタムプロパティ) … この教材のstyle.cssも:rootで色を一元管理しています。テーマ切替やダークモード対応の土台

BEMなどの命名規則だけで戦っていた時代から、言語機能で解決する時代への転換期です。
