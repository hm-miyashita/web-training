# 🌸 0からのホームページ作成研修

本社待機期間中のSE向けスキルアップ研修教材です。新卒・未経験からベテランまで、全レベルを対象にしています。

マスコットの「さくらちゃん」と一緒に、**Webの仕組みの理解から、実際にサイトを作ってインターネットに公開するまで**を一気通貫で学びます。

## 🚀 受講のはじめかた

**この教材はWebサイトとしてそのまま閲覧できます。**

- 公開版:GitHub Pages で公開されている場合は、リポジトリの About 欄のURLからアクセス
- ローカル版:このリポジトリをダウンロード(またはクローン)し、`index.html` をダブルクリックしてブラウザで開く

サーバーもインストールも不要です。ブラウザ(Chrome / Edge 推奨)とVS Codeだけあれば受講できます。

## 📝 受講記録(名前の記入)

トップページの「受講の記録」欄に**日付と名前**を記入して「開始/再開する」を押すと、受講記録がテキストに残ります。

- 記録形式:`何月何日 名前`(1行ずつ)。**1テキスト500行**に達すると `kenshu-log-2.txt` へ自動で切り替わります
- **同じ日付+同じ名前**の記録が既にあれば、二重には記録されません
- **名前を記入しない場合、受講記録は記録されません**(学習自体は可能)
- 途中で中断しても、次回**日付と名前を入力すれば続きの章から再開**できます(進捗は受講者名ごとに保存)

### 記録テキストの保存先(管理者向け)

- Chrome / Edge では、トップページの「管理者向け:記録テキストの設定」から**保存先フォルダを一度指定**すると、以降 `kenshu-log-1.txt` に自動追記されます(社内共有フォルダの指定も可)
- 保存先が未設定・非対応ブラウザの場合は記録がブラウザ内に保存され、「記録テキストをダウンロード」で同形式のテキストを取り出せます

## ✨ 教材の特徴

- **教材サイト自体が教材** — フレームワーク不使用、素のHTML/CSS/JSのみで構築。学習後にソースを読むと復習になります
- **ライブエディタ** — 章内でコードを書き換えると、その場で結果が変わります
- **章末クイズ+進捗管理** — 完了した章はブラウザに記録され、トップページで進捗率を確認できます
- **レベルバッジ** — `基礎`(新卒向け)/ `全員` / `ベテラン向け` の3段階で読み分けができます

## 🧑‍🏫 研修担当者向けメモ

- 成果物(第6章の総合演習)は GitHub Pages の公開URLで提出させる運用を想定しています
- 複数人が同時に待機中の場合は、相互コードレビューと第8章の最終課題(15分LT)の実施を推奨します
